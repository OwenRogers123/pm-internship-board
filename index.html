How it works

Checking 40+ career pages by hand every week for one line of fine print takes hours. So an AI agent does it for me.

1

Scan

Every two days it pulls the big GitHub internship list, searches LinkedIn and Google, and visits about 40 California company career pages.

2

Filter

It opens each posting and reads the actual requirements. A role only makes the list if it passes all three rules below.

3

Update

It rewrites this page and keeps a log of past mistakes, so a closed or wrong role never shows up twice.
